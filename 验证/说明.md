# 环境验证说明

这个脚本用来确认「U 盘游戏启动器」依赖的系统能力在你当前这台电脑和这支 U 盘上是否可用。它不改动任何游戏存档，只在自己创建的临时目录里做实验，跑完自动删干净。

## 怎么运行

1. 插好 U 盘（脚本会自动找；找不到会提示）。
2. 双击 `运行环境验证.cmd`。
3. 看窗口里的 `[PASS]` / `[FAIL]`，最后会生成 `验证报告_<时间>.md`。

U 盘盘符比较特殊时，可以在命令行指定：

```
运行环境验证.cmd -UsbRoot F:\
```

想保留现场排查（不自动删测试目录）：

```
运行环境验证.cmd -UsbRoot F:\ -Keep
```

## 它验证什么

- 目录联接（junction）指向 U 盘目录后，读写是否正常；
- 把 `C:\ProgramData` 下的真实存档目录替换成联接（模拟 PvZ）；
- 双跳链路：存档目录 → 挂载点 → U 盘；换盘符时只重建第二跳；
- 非管理员能否完成上述操作；
- `icacls` 授权、`fsutil` 解析联接目标；
- `robocopy` 接管存档、`/XJ` 不跟随联接；
- 中文/空格路径、只读文件检测；
- 结束后能否清理干净。

## 通过标准

16 项全部 PASS。任何 FAIL 都说明对应能力在当前环境不可用，启动器实现时会走降级分支（复制模式或提示提权）。

## 已有结果

- 2026-11-08，F: TECLAST USB SSD，NTFS，非管理员：**16/16 通过**（见 `验证报告_20261108_214306.md`）。
- 同一支 U 盘格式化为 exFAT 后复跑：**16/16 通过**（见 `验证报告_20261108_215426.md`），说明 exFAT 作为联接目标可用。
- FAT32 还没测过（32 GB 以下小盘常见）；启动器会运行时自测，失败自动转复制模式。
